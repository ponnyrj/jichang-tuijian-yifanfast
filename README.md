## 六步购买前路线

1. 写下使用设备和系统版本；
2. 确认愿意使用官方客户端还是必须使用第三方客户端；
3. 设定真实月付上限，不把年付除以十二当成可月付；
4. 查看测试日期、测试入口和节点覆盖，不只看宣传截图；
5. 从自己的网络打开官网、面板并阅读退款条款；
6. 条件都满足后，用短周期验证，不因优惠直接长期付款。

## 遇到这些情况先停下

- 页面没有写清套餐周期、流量或设备数；
- 客户端支持只来自评论，没有官方确认；
- 测速没有日期、入口或节点范围；
- 只有优惠倒计时，却找不到退款与售后条款；
- 官网或用户面板在自己的网络无法稳定访问。
